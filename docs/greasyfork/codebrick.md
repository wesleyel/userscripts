# CodeBrick 手写作答 OCR + AI 判分

在 CodeBrick 刷题页辅助处理手写作答和复盘。

- 截图题卡，支持预览、复制和下载。
- 将手写作答图片识别为 Markdown。
- 复制题干、我的作答与解析。
- 对照站点解析的踩分点进行 AI 判分。
- 判分完成自动复制结果到剪贴板，关闭弹窗后可直接粘贴。
- 支持多个 OpenAI 兼容模型服务。

## 首次使用

1. 安装脚本，打开 CodeBrick 刷题页。
2. 点击答题区设置，填写自己的服务地址、API Key 和模型。
3. 粘贴或上传作答图片进行识别；需要判分时点击“AI 判分”。

图片及判分所需的题干、作答、解析会发送至你配置的服务。模型服务费用由该服务收取，AI 判分仅供复盘参考。
